# 🌤️ Weather Now

Weather Now is a modern web application that allows users to search for real-time weather information for any city in the world.  
The interface dynamically adapts between light and dark themes based on the **local time of the searched city**, providing a more natural user experience. The project was initially started with the command: npx create-next-app@latest

---

## 🚀 Features

- 🌍 Search weather data for any city worldwide
- 🕒 Displays **local date and time** of the city
- 🌗 Automatic **light / dark theme** based on the city's local hour
- 🌡️ Temperature in Celsius
- 💧 Humidity and 🌬️ wind speed
- ⚡ Fast and responsive UI
- 🎨 Clean, modern design with Tailwind CSS

---

## 🛠️ Technologies Used

- **Next.js (App Router)**
- **React**
- **TypeScript**
- **Tailwind CSS**
- **OpenWeather API**
- **Node.js**

---

## ⚙️ Getting Started

- npm install
- Create a .env.local file in the project root: OPENWEATHER_API_KEY=your_openweather_api_key_here
- npm run dev
- Open http://localhost:3000 in your browser
